# Pali Extensions

Fork for the **Pali** extension repository. Add it in [Mihon](https://mihon.app): Settings > Extensions > Extension repos.

* Repo URL: https://raw.githubusercontent.com/mark-osss/pali-extensions/repo/repo.json
* Source code: https://github.com/mark-osss/pali-extensions-source

The extensions come from the [Keiyoushi extensions](https://github.com/keiyoushi/extensions) project, published under Apache 2.0.
